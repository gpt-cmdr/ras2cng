## What exists now (feature `arrow`; Python `python-arrow`)

- Every catalog layer is Arrow: `mesh_cells`, `mesh_cell_points`, `mesh_faces`,
  `mesh_perimeters`, one layer per 2D summary variable, and the stored feature layers
  `bc_lines`, `breaklines`, `refinement_regions`, `reference_lines`, `reference_points`,
  `mannings_n_regions`, `cross_sections`, `river_centerlines`, `river_bank_lines`,
  `river_edge_lines`, `river_flow_paths`, `structures`, `storage_areas`, `river_junctions`,
  `pump_stations`, `pipe_conduits`, `pipe_nodes`.
- Rust: `session.read_layer(name_or_alias, variable, &LayerOptions)`; `feature_layer`,
  `mesh_cell_points_layer`, plus #41's mesh/summary functions. `CATALOG`, `lookup`,
  `FIELD_ALIASES`, `field_aliases(consumer, layer)`.
- Python: `fh.arrow_layer(path, layer, variable=None, batch_rows=65536, threads=None,
  geometry=False)` -> PyCapsule stream (`pa.table(...)`, zero-copy). `fh.layer_catalog()` ->
  JSON `{"layers": [...], "field_aliases": [...]}`.
- Schema:
  - mesh: `mesh_name` Utf8, `cell_id`/`face_id` Int64 (identity), `geometry` WKB with
    `ARROW:extension:name=geoarrow.wkb`, no CRS attached (caller resolves `Projection`).
  - summaries: `<slug>` stored type (Float32; ints Int64/UInt64; NaN null), `<slug>_time`
    Timestamp(ns, naive; us when all offsets are whole days, as pandas 3) when Time row proven,
    `is_ghost_cell` (cells; ghosts dropped). `geometry=True` appends the cell polygon / face line
    read from the same file. **No all-null union columns.**
  - feature layers: `source_row` Int64, every stored `Attributes` column under its stored name
    (Utf8 / Int64 / UInt64 / Float32 or Float64 as stored, NaN null), `geometry`. Multi-part lines
    -> MultiLineString; multi-part polygons refused; undrawn features null geometry.
- Aliases: layers `mesh_areas`=`mesh_perimeters`, `centerlines`/`river_reaches`=`river_centerlines`,
  `bank_lines`/`edge_lines`=`river_*`. Fields (ras2cng): `bc_line_id`/`bl_id`/`rr_id`/`region_id`/
  `river_id`=`source_row`; breakline `cell_spacing_near`/`cell_spacing_far`/`near_repeats`/
  `protection_radius`; storage area `mode`/`avg_area`/`min_elev`. terrio: `is_ghost`=`is_ghost_cell`.

## Equivalence (reference: ras2cng 0.12.0 working copy, ras-commander 0.110.3, released fast-hdf 0.2.4)

| Check | Files | Result |
|---|---|---|
| Feature layers + `mesh_cell_points` vs ras2cng `_extract_hdf_layer` (rows, order via identity, WKB, every shared column after aliases) | 15 Bald Eagle p07 geometry HDFs, bridges g03, Davis g02 | 272 comparisons (91 non-empty), 0 different, 0 refused |
| mesh_cells/faces/areas + summary values (#41 script, rerun) | above + p07, bridges p05, Davis p02 | 96, 0 different, 3 refused |
| summary `geometry=True` vs ras2cng polygon-mode result layers | p07, p05, p02 | 18 variables, 0 different |

Intentional differences / gaps:
- Types: ras-commander widens some float32 to float64 (breakline spacings, storage `avg_area`/
  `min_elev`, centerline junction distances) and stores `Protection Radius` int64 (stored
  unsigned). Values equal.
- ras2cng-only (derived/joined, not canonical): `length`; cross-section `station_elevation`,
  `mannings_n`, `n_lob/n_channel/n_rob`, `ineffective_blocks`, levee columns; the ~150 joined
  structure columns (bridge coefficients, table info, `Profile_Data`, ...). Canonical-only:
  `source_row` where ras2cng has no id, stored columns ras-commander drops (`Elev Vol Count`).
- `Cell Last Iteration` refused (no stored `Location`); ras2cng p07 archive has it -> needs the
  Python path for that variable.
- Not in any corpus file, so only fixture-tested: refinement regions, reference lines/points,
  flow paths, bank/edge lines, junctions, pipe networks. Multi-part polygons refused.
- No `*_text` layers (text `.gNN` parsing is out of scope for fast-hdf's HDF API).

## For T10 (terrio HECRAS driver on this API)

- Call `ReadOnlyHdfSession::read_layer(name, variable, &LayerOptions)` per layer; the batches are
  already `RecordBatch` with WKB `geometry` (`geoarrow.wkb`) and no CRS. Take the CRS from the stored
  `Projection` as the driver already does.
- Field names are the **stored** names (`SA-2D`, `US River`). terrio's current driver lower-snake-
  cases them (`sa_2d`); keep that as a rename in the driver, or add terrio entries to
  `FIELD_ALIASES` in the same PR so the catalog is the single source. Same for `is_ghost`.
- Behaviour differences vs the current driver to decide: structures without a centerline are a
  row with **null geometry** here (terrio drops the row; ras-commander keeps it with None);
  summary `_time` is Timestamp (ns/us, rounded to 100 ms) here vs stored days f64 in terrio;
  `mesh_cell_points` here is physical cells only, terrio includes ghosts with `is_ghost`.
- Not provided: `mesh_face_points`, joined series/1D results/structure series, cell/face attribute
  joins (`CELL_ATTRIBUTES`, `FACE_ATTRIBUTES`). The driver keeps its typed-API reads for those.
- `geometry=True` re-reads mesh geometry per variable: for many variables read `mesh_cells`/
  `mesh_faces` once and join by `(mesh_name, cell_id|face_id)` (0.21 s vs 0.96 s on p07).
- Refusals are typed (`Unsupported` with code, `NotFound` for an absent family); a default open
  should skip `NotFound` and surface `Unsupported` as the driver does today.
- For the ras2cng archive profile (T03/T11): set `layer` = ras2cng alias and rename fields via
  `field_aliases("ras2cng", layer)`; ras2cng-only derived columns must come from the Python path
  or be dropped in manifest 3.0.
