## Version: 0.3.0.1

- **Base 0.3.0.** That is upstream's latest PyPI release and its latest `python-v*` tag. The fork's `main` also contains upstream commits made after `python-v0.3.0` (in-memory categorical clustering, `a0702a8`..`beb64b0`), but upstream has not released them, so the base stays 0.3.0.
- `python/pyproject.toml` is `0.3.0.1` (written `0.3.0.01` in the brief; PEP 440 normalizes it). maturin takes the wheel version from this file.
- `python/Cargo.toml` and `python/Cargo.lock` say `0.3.0+gpt-cmdr.1`, because Cargo needs SemVer. The crate is `publish = false`.
- **Tag `v0.3.0.1-gpt-cmdr`** (on `1a55582`). It does not collide with upstream's `vX.Y.Z` (R) or `python-vX.Y.Z` tags. **Never push a `python-v*` tag on the fork:** the workflow's `publish-pypi` job runs on that prefix.

## Published

It has 14 assets:
- Windows `win_amd64` wheels for cp39-cp314
- Linux `manylinux_2_28_x86_64` wheels for cp39-cp314
- The sdist `freestiler-0.3.0.1.tar.gz`

All of them were built by the fork's own workflow on the tag, with the default features (GeoParquet, DuckDB, Arrow). CI also built macOS wheels; they are not attached, per the scope of this task. No local build was needed. The local copies are in `G:\RustDev\work\R4\release\assets`.
