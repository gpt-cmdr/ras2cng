**The locked suites do not test what a user installs.** A fresh `ras2cng[all]` resolves about 100 packages newer than `uv.lock`, including terrio 0.7.0, so I ran the suite on that too. **Both failures are in the tests, not in shipped code, and I did not fix them:**

1. `test_writer_uses_bbox_struct_covering_and_layer_row_groups`: the test calls `duckdb.sql(...).fetchone()`, which DuckDB 2.0 removed. Nothing in `ras2cng/` calls it. Use `.fetchall()`.
2. `test_refused_crs_is_reprojected_in_python`: the test's fake freestiler refuses any CRS text containing `HARN`, and PROJ 9.8's PROJJSON for EPSG:2271 has a datum remark naming NAD83(HARN). Match on the datum, not the whole text. **Not tested: whether the real freestiler reads that remark as a refusal.** Bald Eagle is EPSG:2271 and was not run on these versions; a refusal would fall back to reprojecting in Python.

Anyone running the tests unlocked will see these two until they are fixed.
