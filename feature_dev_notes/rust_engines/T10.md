## For T11

1. **Always pass `crs=`.** The path reads only the HDF's stored `Projection`. 14 of the 15 Bald Eagle geometry HDFs store none, and writes then give `crs: null` with no error. ras2cng's project-level CRS (`_detect_project_crs`) must be passed. With it the `geo` CRS is identical JSON to the oracle's (checked on g04). Also pass it where a `Projection` is stored: g09 and p07 convert to a PROJJSON with no EPSG id that is not `pyproj` `equals` to EPSG:2271 (same unit, about 1e-14 degrees apart at one tested point).
2. **Refusals are returned, not raised.** Read `skipped` and fill from the Python path through `extra_layers`, or fall back for that file. Expect `cell_last_iteration` on p07, and on older files either every summary (Location absent) or a whole family (Spring_BLE breaklines).
3. **`layer_rows` covers HDF layers only**, not `extra_layers`. Use `rows`/`layers` for totals.
4. **Decide what manifest 3.0 does with v2-only content:** `river_reaches`, joined `structures` and `cross_sections` columns, `length`. These must come from Python as extra layers or be dropped explicitly. `extra_layers` adds layers, not columns, so filling a column means replacing that layer.
5. **Extra-layer columns must have the same types** (only Null unifies). The direct float32 and uint64 columns differ from the v2 float64 and int64, so mixing Python frames for the same column name across layers can be refused. Not exercised on real data.
6. **Defaults add content:** `ghost_cell_points=True` and `time_days=True`. Use `time_days=False` and `layers=[...]` to leave them out.
7. **Capability-detect** `terrio._terrio.write_hecras_archive`. It exists only on this unreleased fork build. The engine pin is a git rev, so `cargo publish` is blocked until fast-hdf releases. The fork version 0.5.0 also collides with PyPI (T04).
8. **Family NaN is null** in this path, and a `structures` row without a centerline has null geometry.
