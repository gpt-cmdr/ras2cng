    mapping¶

    Result raster generation for HEC-RAS projects using the RASMapper engine.

    Overview¶

    The mapping module generates georeferenced raster files (GeoTIFF) from completed HEC-RAS plan results. It uses a private compatibility adapter around ras-commander's stored-map APIs so profile selection is explicit and validated before map generation mutates the project.

    Max and Min remain explicit summary selections. An exact named steady profile is resolved from the plan HDF and sent through RasMap.store_all_maps(mode="steady_profiles"); a missing or duplicate name raises an error instead of silently producing Max. Unsteady timestamps are likewise validated exactly. Whole-simulation products such as arrival time are generated separately because they do not have a profile dimension.

    On Linux, RasProcess.exe runs under Wine. See the Linux/Wine Setup guide.

    Supported Map Types¶

    Map Type CLI Flag Default Description
    wse --wse/--no-wse On Water Surface Elevation
    depth --depth/--no-depth On Depth
    velocity --velocity/--no-velocity On Velocity
    froude --froude Off Froude Number
    shear_stress --shear-stress Off Shear Stress
    depth_x_velocity --dv Off Depth x Velocity
    depth_x_velocity_sq --dv-sq Off Depth x Velocity²
    inundation_boundary --inundation-boundary Off Inundation Boundary (GeoJSON from the default fast-map engine, much faster; shapefile from RAS Mapper)
    arrival_time --arrival-time Off Arrival Time (hours, whole-simulation)
    duration --duration Off Inundation Duration (hours, whole-simulation)
    percent_inundated --percent-inundated Off Percent Time Inundated (whole-simulation)

    --recession is accepted for compatibility but ignored with a warning — RasMapperLib has no recession map type, and only RasMapperLib-native outputs are produced.

    Whole-simulation map types¶

    arrival_time, duration, and percent_inundated are computed over the entire simulation — the --profile option does not apply to them. Their filenames carry the --arrival-depth wet/dry threshold instead of the profile name, e.g. Arrival Time (0.1ft hrs).tif. They work with any ras-commander version: newer versions generate them natively via store_maps(); on older versions ras2cng pre-injects the stored-map entries into the .rasmap (restored afterwards) so the same StoreAllMaps run produces them.

    Generating these types causes RasMapperLib to build a PostProcessing.hdf cache that can exceed the plan HDF in size; ras2cng deletes it from the output directory unless --keep-postprocessing is passed.

    Local performance policy¶

    The default DEFAULT_LOCAL_MAP_PERFORMANCE preset is tuned for local processing on the 8-core, 31.8 GiB development workstation:

    • memory-aware automatic helper selection (max_workers=None);
    • enforced memory admission with an 8192 MiB / 25 percent reserve;
    • one GDAL thread per helper to prevent nested oversubscription;
    • a 64 MiB GDAL cache cap charged to every helper's memory estimate.

    Only independent WSE, Depth, and Velocity products run concurrently. Large terrain estimates and products that require shared ordered state automatically use one helper. On the Spring River fixture, the measured estimate is about 11.2 GiB per helper, so this 31.8 GiB machine remains serial; a machine with more available memory can admit two or three map helpers without changing the call.

    Use --map-workers 1 for a controlled serial comparison, or set the helper ceiling, reserve, and cache explicitly:

    ras2cng map model.prj ./maps \
  --map-workers 2 \
  --map-reserve-memory-mb 8192 \
  --map-gdal-cache-mb 64

    Python callers can provide the full typed policy without adding a second map function:

    from ras_commander import StoreMapPerformanceOptions
from ras2cng import generate_result_maps

results = generate_result_maps(
    "model.prj",
    "maps",
    performance=StoreMapPerformanceOptions(
        max_workers=None,
        reserve_memory_mb=8192,
        gdal_cachemax_mb=64,
    ),
)

    Render Mode¶

    The --render-mode option controls how the water surface is rendered to raster grids. This is critical for pixel-perfect output — HEC-RAS 6.x's RasProcess.exe ignores the render mode from the .rasmap file, so ras-commander uses RasStoreMapHelper.exe to set the mode explicitly before generating maps.

    Mode Flag Description
    horizontal --render-mode horizontal Flat water surface within each mesh cell (default)
    sloping --render-mode sloping Interpolated sloping water surface
    slopingPretty --render-mode slopingPretty Sloping with depth-weighted face reduction (HEC-RAS 6.4+)

    If --render-mode is not specified, the mode is read from the project's .rasmap file (defaults to horizontal if not set).

    # Generate maps with sloping render mode
ras2cng map /path/to/project /output/maps --render-mode sloping

# Archive with slopingPretty render mode (requires HEC-RAS 6.4+)
ras2cng archive /path/to/project ./archive/ --results --map --render-mode slopingPretty

    Mapping engine: RAS Mapper or fast-map¶

    fast-map is the default engine. It maps selected products through the Rust ras-commander-fast-map engine and hands everything else to RAS Mapper (RasStoreMapHelper.exe) per product group, printing the reason; --engine rasmapper (or RAS2CNG_MAP_ENGINE=rasmapper) renders every product through RAS Mapper. The water-surface render mode comes from the project's .rasmap, as RAS Mapper takes it (--render-mode overrides it); a project with no stored mode goes to RAS Mapper, which applies its own default. fast-map is built for FIM library creation on pure 2D models, not for general use across all model types: every fast-map product is qualified against RAS Mapper output (pixel conformance against native HEC-RAS 7.0.1 stored maps on the named models), and everything else falls back to RAS Mapper. ras-commander installs the engine through ras-commander[full] on Windows x64 and Linux x64 (ras2cng[fast-map] requests it explicitly). The mapping arithmetic needs no GDAL, and with the source-terrain path below no HEC-RAS either.

    # Default: Rust WSE/Depth, arrival time and percent inundated; the rest via RAS Mapper
ras2cng map /path/to/project /output/maps \
    --arrival-time --percent-inundated --arrival-depth 0.5 --ras-version 7.0.1

# Everything through RAS Mapper
ras2cng map /path/to/project /output/maps --engine rasmapper

# Reuse a terrain export across runs
ras2cng map /path/to/project /output/maps --engine fast-map \
    --fast-map-terrain /output/maps/_fast_map_terrain/Terrain50.tif

# Fail instead of falling back (qualification runs)
ras2cng map /path/to/project /output/maps --engine fast-map --fast-map-strict

# Map a plan with storage areas in Rust (opt-in; otherwise RAS Mapper maps it)
ras2cng map /path/to/project /output/maps --fast-map-storage-areas

    RAS2CNG_MAP_ENGINE selects the engine everywhere, including ras2cng archive --map. Scope, engine and render mode are checked from the plan HDF and .rasmap before any terrain work, so an out-of-scope plan goes to RAS Mapper without a terrain export.

    Terrain. With ras-commander's RasFim.top_priority_terrain_source (ras-commander #724, fast-map #11), ras2cng maps on the terrain's unmodified priority-1 source TIFF, with its terrain-HDF footprint mask, and skips the RAS Mapper terrain export. Inside that footprint the source TIFF is the effective terrain, and the engine refuses when a wet cell would draw outside it. ras2cng then:

    1. retries on the source's CRS-canonical copy, only when the refusal was about the CRS (Davis);
    2. otherwise builds the native effective terrain once per run, when the engine advertises rasmapper-effective-terrain/1 and RasFim has build_effective_terrain: RAS Mapper's multi-source mosaic (stitch TIN first, then each source in priority order) rebuilt in Rust from the source TIFFs, their level-0 masks and the stitch TIN, without HEC-RAS. On Bald Eagle Terrain50 the valid mask is identical on 197,179,058 px and 8 values differ, all in stitch-TIN corners where RAS Mapper's own exports disagree (max 1.53 ft); it took 7.0 s and 1.4 GB, against about 190 s for the export. Terrains with modifications are refused;
    3. otherwise exports the plan's terrain once per run through RAS Mapper (RasTerrain.export_rasmapper_terrain, HEC-RAS 6.4.1/6.5/6.6/7.0.1/7.1; pass --ras-version).

    --fast-map-terrain supplies a float32 export (with modifications) instead, --no-fast-map-effective-terrain skips step 2, and --no-fast-map-source-terrain skips the source TIFF.

    Terrains with modifications always go to RAS Mapper. Before any of the steps above, ras2cng reads the terrain HDF's /Modifications group and the .rasmap's modification layers (ras2cng.terrain.terrain_modifications). If it finds any, or cannot read the terrain HDF, steps 1 and 2 are skipped and RAS Mapper's export builds the terrain (step 3), and the inundation boundary is drawn by RAS Mapper. Rust terrain operations run only on unmodified terrains, even with an engine build that accepts modifications: that work is parked because it does not yet reproduce RAS Mapper on real modified terrains. map-hdf with a single raw --terrain TIFF passes that TIFF directly.

    Output. Products are named like RAS Mapper's (WSE (Max).tif, Depth (Max).tif, Velocity (Max).tif, D _ V (Max).tif, D _ V^2 (Max).tif, Froude (Max).tif, Arrival Time (0.5ft hrs).tif, Duration (0.5ft hrs).tif, Percent Time Inundated (0.5ft).tif) on the terrain's pixel grid, with NaN nodata, next to fast_map_manifest.json, fast_map_velocity_manifest.json, fast_map_derived_manifest.json and fast_map_whole_simulation_manifest.json (engine version, method, terrain, storage areas, timings). Arrival time is in hours since the simulation start. MapResult.engines records which engine produced each map type, MapResult.fast_map_skipped why a map type went to RAS Mapper under the fast-map engine (for example storage areas without the opt-in), and MapResult.fast_map_terrain which terrain fast-map used (source, source-canonical, effective, export or supplied). Velocity is its own engine call, so a velocity refusal never costs WSE/Depth, and WSE/Depth keep the native GeoTIFF writer; in horizontal mode it is rendered plain sloping and clipped with the horizontal depth, as RAS Mapper does. --min-depth, --wgs84 and --cog apply unchanged. Other options: --fast-map-threads (default CPUs − 1) and --fast-map-memory-mib (planned working memory; default a quarter of RAM, 1–16 GiB).

    Invalid cell polygons. HEC-RAS can compute 2D cells whose face polylines cross. With ras-commander 0.110.2 or newer, fast-map maps those meshes under an explicit policy instead of refusing them:

    --fast-map-invalid-cells Pixel ownership of an invalid cell
    repair (engine default) polygonize the cell's faces, remove area owned by valid cells, keep the largest part
    hull the face-point convex hull, with the same overlap removal
    omit the cell owns no pixels
    raise refuse; the products fall back to RAS Mapper (--fast-map-strict raises)

    Hydraulic connectivity and interpolation always use the complete HDF topology; only pixel ownership changes. RAS Mapper's own rendering of such cells has not been qualified against repair. Every affected cell (mesh, cell id, reason, action, original and mapped area) is recorded as fim-invalid-cells/1 in MapResult.invalid_cells, fast_map_manifest.json and fast_map_whole_simulation_manifest.json, and a non-zero count is printed.

    GeoTIFF delivery. With ras-commander-fast-map 0.11 the engine writes the sloping WSE/Depth GeoTIFFs itself (terrio, LZW) instead of handing float32 arrays back to Python for rasterio. --fast-map-writer auto (default) uses it when the engine supports it and velocity is not requested; native requires it and rasterio keeps the previous path (RAS2CNG_FAST_MAP_WRITER sets the default). On Bald Eagle bridges p05 Max the two writers gave identical pixels and the same LZW strip layout; native files were about 4% smaller and the engine call used about 18% less peak memory. --cog converts either through the shared COG policy with identical results. MapResult.fast_map_writer records the writer.

    Inundation boundaries in Rust (recommended with fast-map)¶

    RAS Mapper's inundation-boundary export is very slow. With fast-map (the default engine), --inundation-boundary is mapped by the Rust engine (RasFim.map_inundation_boundaries) whenever the plan is in scope. In ras-commander's Davis pipes/conduits comparison, the Rust batch for Max plus one timestep took 3.5 s against 85 s for the two native RAS Mapper calls. It is not the default engine, but it is the recommended way to produce boundaries for pure 2D models.

    # Rust WSE/Depth and boundary; velocity still through RAS Mapper
ras2cng map /path/to/project /output/maps --engine fast-map --inundation-boundary

# Explicit single-source terrain HDF (its TIFF is found beside it)
ras2cng map /path/to/project /output/maps --engine fast-map --inundation-boundary \
    --fast-map-terrain-hdf /path/to/project/Terrain/Terrain.hdf

# Keep boundaries on RAS Mapper while still using Rust rasters
ras2cng map /path/to/project /output/maps --engine fast-map --inundation-boundary \
    --no-fast-map-boundary

    It is a different method, not a copy of RAS Mapper's polygons. The Rust engine traces deterministic zero-depth contours (deterministic-zero-depth-contours/1): the same inputs always give byte-identical GeoJSON, on Windows and Linux and at any worker count. RAS Mapper's own boundary polygons are order-dependent and can differ between identical exports, so the two are close but not equal. On Davis Max the Rust contour had 66 holes and 47,426 vertices, against RAS Mapper's 65 and 47,396. Almost all of the 7,423 ft² difference was one hole that RAS Mapper filled. The Depth/WSE rasters are unaffected; they still match RAS Mapper bit for bit.

    Extra scope for boundaries, on top of the pure-2D rules above (each falls back to RAS Mapper on its own, so the rasters can still use Rust):

    Condition Why
    Terrain with more than one source TIFF The method needs the original terrain HDF's masks, perimeters and stitch TIN for a single source. The flattened raster export cannot stand in for them
    Terrain modifications Refused by ras2cng before the engine runs (terrain_modifications): modified terrains always go to RAS Mapper
    slopingPretty render mode Contours support horizontal and plain sloping only
    ras-commander without RasFim.map_inundation_boundaries Needs ras-commander 0.113.0
    Storage areas The contour method draws 2D cells only; the level pool would be missing
    A terrain CRS the engine and rasterio read differently (Davis), without --fast-map-terrain-crs-hash The engine cannot name an EPSG code for it; ras2cng never guesses the identity (see below)

    User-supplied terrain CRS. When the engine cannot name the terrain's EPSG code and reads its WKT differently from rasterio (Davis), the boundary falls back to RAS Mapper, and the message prints the engine's WKT hash, for example:

    engine terrain CRS differs from rasterio CRS EPSG:2871; the engine reports
crs_wkt_fnv1a64=e446f7bd6bdb4d7f for Terrain (1).Davis_terrain2.tif ...

    Check the CRS first (ras2fim-batch terrain-info <terrain.tif> prints the engine's WKT and crs_wkt_fnv1a64), then pass the hash:

    ras2cng map /path/to/Davis /output/maps --inundation-boundary \
    --fast-map-terrain-crs-hash e446f7bd6bdb4d7f

    The Python API takes fast_map_terrain_crs_fnv1a64=. It applies to the boundary terrain only, is used only when the engine reports no EPSG code, and a value that does not equal the engine's hash is refused. The boundary manifest records it as ras2cng.terrain_crs_fnv1a64.

    Output. Inundation Boundary (Max).geojson: a MultiPolygon with holes, in the model CRS. RAS Mapper writes a shapefile. It sits next to fast_map_boundary_manifest.json, which records the method, polygon/hole/vertex counts, area, terrain and timings. A plan with no flooded area writes no boundary.

    Post-Processing Options¶

    • Minimum depth threshold (--min-depth): Set pixels below a depth threshold to NoData
    • WGS84 reprojection (--wgs84): Reproject output rasters to EPSG:4326 using rasterio
    • Cloud Optimized GeoTIFF (--cog): Convert output to COG using gdal_translate

    # Validate fast-map options before any project or engine work.
    fast_map_invalid_cells = _fast_map.normalize_invalid_cells(fast_map_invalid_cells)
    fast_map_writer = _fast_map.resolve_product_writer(fast_map_writer)
    fast_map_storage_areas = _fast_map.resolve_storage_areas(fast_map_storage_areas)
    fast_map_terrain_crs_fnv1a64 = _fast_map.normalize_crs_fnv1a64(
        fast_map_terrain_crs_fnv1a64
    )

    # Absolute: RAS Mapper resolves a relative folder against the project, so
    # its rasters would land under the project instead of here.
    output_dir = Path(output_dir).resolve()
    output_dir.mkdir(parents=True, exist_ok=True)

    project_dir, prj_file = resolve_project_path(project_path)

    console.print(f"\n[bold cyan]ras2cng map[/bold cyan] -> {output_dir}")
    console.print(f"  Project : {prj_file.name}")
    console.print(f"  Profile : {profile}")

    engine = _fast_map.resolve_map_engine(map_engine)
    terrain_resolver = None
    if engine == _fast_map.FAST_MAP:
        rust_products = ["WSE/Depth"]
        if fast_map_velocity is not False:
            rust_products.append("velocity")
        if fast_map_derived:
            rust_products.append("D x V/Froude (Max)")
        if fast_map_whole_simulation:
            rust_products.append("arrival time/percent inundated/duration")
        if fast_map_boundary:
            rust_products.append("inundation boundary")
        if fast_map_storage_areas:
            rust_products.append("storage areas (opt-in)")
        console.print(
            f"  Engine  : fast-map (Rust) for {', '.join(rust_products)} on pure 2D "
            "models (FIM library scope) where the installed engine is qualified; "
            "RAS Mapper for everything else"
        )
        terrain_resolver = _fast_map.TerrainResolver(
            prj_file,
            output_dir / "_fast_map_terrain",
            terrain_path=fast_map_terrain,
            terrain_name=terrain_name,
            ras_version=ras_version,
            terrain_hdf=fast_map_terrain_hdf,
            effective=fast_map_effective_terrain,
            threads=fast_map_threads,
            max_working_mib=fast_map_memory_mib,
        )
    else:
        console.print("  Engine  : RAS Mapper")

    optimized_store_maps = _supports_optimized_store_maps()
    if performance is not None and not optimized_store_maps:
        raise RuntimeError(
            "performance requires ras-commander>=0.99.0; upgrade ras-commander "
            "or omit performance to use the serial compatibility path"
        )
    if performance is not None:
        effective_performance = performance
    elif optimized_store_maps:
        effective_performance = DEFAULT_LOCAL_MAP_PERFORMANCE
    else:
        effective_performance = None
    if effective_performance is not None:
        worker_label = (
            "auto"
            if effective_performance.max_workers is None
            else str(effective_performance.max_workers)
        )
        console.print(
            f"  Mapping : {worker_label} helper(s), "
            f"{effective_performance.memory_policy} memory admission"
        )
    else:
        console.print("  Mapping : serial compatibility path")

    # Configure RasProcess
    _configure_rasprocess(rasprocess_path, ras_version)

    # Initialize project (pass ras_version to avoid auto-detecting old versions from plan files)
    init_kwargs = dict(ras_object="new", load_results_summary=True)
    if ras_version:
        init_kwargs["ras_version"] = ras_version
    ras = init_ras_project(project_dir, **init_kwargs)
    if rasprocess_path:
        exe_path = Path(rasprocess_path)
        ras.ras_exe_path = str(
            exe_path
            if exe_path.suffix.lower() == ".exe"
            else exe_path / "RasProcess.exe"
        )

    # RasMapperLib has no recession MapType (verified 6.6/7.0.1) — only
    # RasMapperLib-native products are generated.
    if recession:
        console.print(
            "  [yellow]Warning:[/yellow] recession has no RasMapperLib map type "
            "- skipping (arrival_time and duration are available)"
        )
        recession = False

    # Build list of requested map types
    requested_types = _build_requested_types(
        wse=wse, depth=depth, velocity=velocity,
        froude=froude, shear_stress=shear_stress,
        depth_x_velocity=depth_x_velocity,
        depth_x_velocity_sq=depth_x_velocity_sq,
        inundation_boundary=inundation_boundary,
        arrival_time=arrival_time, duration=duration,
        percent_inundated=percent_inundated,
    )

    if not requested_types:
        console.print("[yellow]Warning:[/yellow] No map types selected")
        return []

    if "inundation_boundary" in requested_types and (reproject_wgs84 or convert_cog):
        console.print(
            "  [yellow]Note:[/yellow] raster post-processing (--wgs84/--cog) does "
            "not apply to the inundation boundary shapefile - it stays in the "
            "model CRS"
        )

    console.print(f"  Map types: {', '.join(requested_types)}")

    # Determine which plans to process
    plan_filter = set(plans) if plans else None
    plan_rows = ras.plan_df if ras.plan_df is not None and not ras.plan_df.empty else None

    if plan_rows is None:
        console.print("[yellow]Warning:[/yellow] No plans found in project")
        return []

    results: list[MapResult] = []

    for _, row in plan_rows.iterrows():
        plan_num = str(row.get("plan_number", "")).zfill(2)
        plan_id = f"p{plan_num}"

        if plan_filter and plan_id not in plan_filter:
            continue

        plan_hdf = project_dir / f"{ras.project_name}.p{plan_num}.hdf"
        if not plan_hdf.exists():
            console.print(f"  [{plan_id}] No HDF results - skipping")
            continue

        plan_output = output_dir / plan_id
        plan_output.mkdir(parents=True, exist_ok=True)

        map_result = MapResult(
            plan_id=plan_id,
            plan_number=plan_num,
            output_dir=plan_output,
        )

        console.print(f"  [{plan_id}] Generating maps...")

        try:
            fast_results: dict[str, list[Path]] = {}
            fast_render = None
            if terrain_resolver is not None:
                # Scope, engine and render mode first: an out-of-scope plan
                # (1D, storage areas, no stored render mode) must not pay for
                # a terrain export before going to RAS Mapper.
                try:
                    fast_render = _fast_map.preflight(
                        plan_hdf, ras, render_mode, storage_areas=fast_map_storage_areas,
                    )
                except _fast_map.FastMapUnavailable as exc:
                    if not fast_map_fallback:
                        raise
                    console.print(
                        f"    [yellow]fast-map not used[/yellow] ({exc}); using RAS Mapper"
                    )
                    for map_type in requested_types:
                        map_result.fast_map_skipped[map_type] = str(exc)
            if fast_render is not None:
                # WSE/Depth and the boundary use different terrain inputs, so
                # each falls back to RAS Mapper on its own.
                def _fast_group(label, run, types=()):
                    try:
                        produced = run()
                    except Exception as exc:
                        if not fast_map_fallback:
                            raise
                        console.print(
                            f"    [yellow]fast-map {label} unavailable[/yellow] "
                            f"({exc}); using RAS Mapper"
                        )
                        for map_type in types:
                            if map_type in requested_types:
                                map_result.fast_map_skipped[map_type] = str(exc)
                        return {}
                    console.print(
                        f"    fast-map: {', '.join(produced)} mapped in Rust"
                    )
                    record = getattr(produced, "invalid_cells", None)
                    writer = getattr(produced, "product_writer", None)
                    for map_type in produced:
                        if record is not None:
                            map_result.invalid_cells[map_type] = record
                        if writer is not None:
                            map_result.fast_map_writer[map_type] = writer
                    if record and record.get("count"):
                        console.print(
                            f"    [yellow]fast-map {label}:[/yellow] {record['count']} invalid "
                            f"2D cell polygon(s) handled with invalid_cells="
                            f"{record.get('policy')!r} (see the fast-map manifest)"
                        )
                    return produced

                def _on_terrain(label, run):
                    """Run on the cheapest terrain the engine accepts; record it."""
                    notes_before = len(terrain_resolver.notes)
                    produced, kind = _fast_map.with_terrain(
                        terrain_resolver, plan_hdf, run, use_source=fast_map_source_terrain,
                    )
                    for note in terrain_resolver.notes[notes_before:]:
                        console.print(f"    fast-map {label}: {note}")
                    for map_type in produced:
                        map_result.fast_map_terrain[map_type] = kind
                    return produced

                def _skip(label, reason, *, strict=False, types=()):
                    """A product group outside fast-map's scope goes to RAS Mapper.

                    ``strict``: also refused under --fast-map-strict (as the
                    per-profile maps always were); qualification limits such
                    as slopingPretty velocity are not errors. ``types`` are
                    recorded in ``MapResult.fast_map_skipped``.
                    """
                    if strict and not fast_map_fallback:
                        raise _fast_map.FastMapUnavailable(f"{label}: {reason}")
                    for map_type in types:
                        if map_type in requested_types:
                            map_result.fast_map_skipped[map_type] = reason
                    console.print(
                        f"    [yellow]fast-map {label} not used[/yellow] ({reason}); "
                        "using RAS Mapper"
                    )

                # Per-profile products are Max only through fast-map. Decided
                # here, before any terrain work: inside with_terrain a refusal
                # reads as a terrain refusal and would cost an export.
                max_profile = profile == "Max"
                profile_reason = f"fast-map maps the Max profile only (got {profile!r})"
                if not max_profile and any(
                    t in requested_types
                    for t in (*_fast_map.FAST_MAP_RASTER_TYPES, "velocity",
                              *_fast_map.FAST_MAP_DERIVED_TYPES, _fast_map.FAST_MAP_BOUNDARY)
                ):
                    _skip("per-profile maps", profile_reason, strict=True, types=(
                        *_fast_map.FAST_MAP_RASTER_TYPES, "velocity",
                        *_fast_map.FAST_MAP_DERIVED_TYPES, _fast_map.FAST_MAP_BOUNDARY,
                    ))
                if max_profile and any(
                    t in _fast_map.FAST_MAP_RASTER_TYPES for t in requested_types
                ):
                    fast_results.update(_fast_group("WSE/Depth", lambda: _on_terrain(
                        "WSE/Depth",
                        lambda tif, hdf, kind: _fast_map.map_plan(
                            plan_hdf,
                            tif,
                            plan_output,
                            map_types=requested_types,
                            profile=profile,
                            render=fast_render,
                            threads=fast_map_threads,
                            timeout=timeout,
                            max_working_mib=fast_map_memory_mib,
                            terrain_hdf=hdf,
                            terrain_kind=kind,
                            invalid_cells=fast_map_invalid_cells,
                            product_writer=fast_map_writer,
                        ),
                    ), types=_fast_map.FAST_MAP_RASTER_TYPES))
                if max_profile and "velocity" in requested_types:
                    velocity_depth, reason = _fast_map.velocity_plan(
                        fast_render, fast_map_velocity
                    )
                    if reason is not None:
                        _skip("velocity", reason, types=("velocity",))
                    else:
                        fast_results.update(_fast_group("velocity", lambda: _on_terrain(
                            "velocity",
                            lambda tif, hdf, kind: _fast_map.map_velocity(
                                plan_hdf,
                                tif,
                                plan_output,
                                render=fast_render,
                                velocity_depth=velocity_depth,
                                profile=profile,
                                threads=fast_map_threads,
                                timeout=timeout,
                                max_working_mib=fast_map_memory_mib,
                                terrain_hdf=hdf,
                                terrain_kind=kind,
                                invalid_cells=fast_map_invalid_cells,
                            ),
                        ), types=("velocity",)))
                derived_types = [
                    t for t in _fast_map.FAST_MAP_DERIVED_TYPES if t in requested_types
                ]
                if max_profile and derived_types:
                    reason = _fast_map.derived_plan(fast_render, fast_map_derived)
                    if reason is not None:
                        _skip("D x V/Froude", reason, types=derived_types)
                    else:
                        fast_results.update(_fast_group("D x V/Froude", lambda: _on_terrain(
                            "D x V/Froude",
                            lambda tif, hdf, kind: _fast_map.map_derived(
                                plan_hdf,
                                tif,
                                plan_output,
                                map_types=derived_types,
                                render=fast_render,
                                profile=profile,
                                threads=fast_map_threads,
                                timeout=timeout,
                                max_working_mib=fast_map_memory_mib,
                                terrain_hdf=hdf,
                                terrain_kind=kind,
                                invalid_cells=fast_map_invalid_cells,
                            ),
                        ), types=derived_types))
                whole_types, whole_notes = _fast_map.whole_simulation_types(
                    requested_types, fast_render
                )
                for note in whole_notes if fast_map_whole_simulation else ():
                    _skip("whole simulation", note)
                if fast_map_whole_simulation and whole_types:
                    fast_results.update(_fast_group("whole simulation", lambda: _on_terrain(
                        "whole simulation",
                        lambda tif, hdf, kind: _fast_map.map_whole_simulation(
                            plan_hdf,
                            tif,
                            plan_output,
                            map_types=whole_types,
                            threshold=arrival_depth,
                            render=fast_render,
                            terrain_hdf=hdf,
                            threads=fast_map_threads,
                            timeout=timeout,
                            max_working_mib=fast_map_memory_mib,
                            terrain_kind=kind,
                            invalid_cells=fast_map_invalid_cells,
                        ),
                    ), types=whole_types))
                if (
                    max_profile and fast_map_boundary
                    and _fast_map.FAST_MAP_BOUNDARY in requested_types
                ):
                    def _boundary():
                        tif, terrain_hdf = terrain_resolver.boundary_terrain(plan_hdf)
                        return _fast_map.map_boundary(
                            plan_hdf, tif, terrain_hdf, plan_output,
                            profile=profile,
                            render=fast_render,
                            terrain_crs_fnv1a64=fast_map_terrain_crs_fnv1a64,
                            threads=fast_map_threads,
                            timeout=timeout,
                            max_working_mib=fast_map_memory_mib,
                            invalid_cells=fast_map_invalid_cells,
                        )
                    fast_results.update(_fast_group(
                        "inundation boundary", _boundary, types=(_fast_map.FAST_MAP_BOUNDARY,)
                    ))

            rasmapper_types = [t for t in requested_types if t not in fast_results]

            # Build boolean flags for RasProcess.store_maps()
            type_flags = {t: (t in rasmapper_types) for t in MAP_TYPE_VARIABLES}

            plan_run_started = time.time() - 2  # filesystem mtime slack

            result_dict: dict[str, list[Path]] = {}
            if rasmapper_types:
                result_dict = _generate_plan_maps(
                    ras=ras,
                    plan_number=plan_num,
                    profile=profile,
                    output_dir=plan_output,
                    terrain_name=terrain_name,
                    render_mode=render_mode,
                    timeout=timeout,
                    arrival_depth=arrival_depth,
                    ras_version=ras_version,
                    performance=effective_performance,
                    **type_flags,
                )
            for map_type in rasmapper_types:
                map_result.engines[map_type] = _fast_map.RASMAPPER
            for map_type, paths in fast_results.items():
                result_dict[map_type] = paths
                map_result.engines[map_type] = _fast_map.FAST_MAP

            # Shapefile outputs (inundation boundary) are moved by store_maps
            # but not included in its TIF-oriented return dict — glob them,
            # restricted to files produced by this run.
            if "inundation_boundary" in requested_types and not result_dict.get("inundation_boundary"):
                shp_paths = sorted(
                    p for p in plan_output.glob("*.shp")
                    if p.stat().st_mtime >= plan_run_started
                )
                if shp_paths:
                    result_dict["inundation_boundary"] = shp_paths

            for map_type in requested_types:
                tif_paths = result_dict.get(map_type, [])

                # Raster post-processing does not apply to shapefile outputs
                if map_type != "inundation_boundary":
                    # Post-process: depth threshold
                    if map_type == "depth" and min_depth > 0.0:
                        tif_paths = _apply_depth_threshold(tif_paths, min_depth)

                    # Post-process: reproject to WGS84
                    if reproject_wgs84:
                        tif_paths = _reproject_tifs(tif_paths, "EPSG:4326")

                    # Post-process: convert to COG
                    if convert_cog:
                        tif_paths = _convert_to_cog(tif_paths, map_type=map_type)

                if tif_paths:
                    map_result.map_types[map_type] = tif_paths
                    console.print(f"    {map_type}: {len(tif_paths)} raster(s)")

            postprocessing_hdf = plan_output / "PostProcessing.hdf"
            if postprocessing_hdf.exists() and not keep_postprocessing:
                size_mb = postprocessing_hdf.stat().st_size / 1e6
                postprocessing_hdf.unlink()
                console.print(f"    Removed PostProcessing.hdf cache ({size_mb:.0f} MB)")

        except Exception as e:
            error_msg = f"plan {plan_id}: {e}"
            map_result.errors.append(error_msg)
            console.print(f"    [yellow]Warning:[/yellow] {error_msg}")
            if not skip_errors:
                raise

        results.append(map_result)

    total_maps = sum(
        sum(len(paths) for paths in r.map_types.values())
        for r in results
    )
    total_errors = sum(len(r.errors) for r in results)
    console.print(f"\n[green]OK[/green] Generated {total_maps} raster(s) from {len(results)} plan(s)")
    if total_errors:
        console.print(f"  [yellow]{total_errors} error(s)[/yellow]")

    return results
